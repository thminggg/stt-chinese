# Convert Simplified Chinese to Traditional Chinese

An implementation runs in local to convert Simplified Chinese to Traditional Chinese

## Tech Stacks

1. Python
1. [opecc](https://github.com/BYVoid/OpenCC)
1. [Flask](https://flask.palletsprojects.com/en/latest/api/)

## Setup Virtual Environment

Open a terminal and create a virtual environment using Python:

```bash
# create a virtual env
python -m venv venv

# activate the virtual env
source venv/bin/activate

# install required packages
 pip install -r requirements.txt
```

## (Optional) Set Python3 as default Python

```bash
# can add this line to .zshrc
alias python=python3
```

## Run the main program

```bash
python app.py
```
